    Replace the stub in src/lib/db/schema.ts with the full schema. Use explicit SQL column names (Option A from research) to match the Electron schema snake_case naming. This ensures PostgreSQL columns are named full_name, hire_date, etc. — not fullName, hireDate.

    ```typescript
    import {
      pgTable,
      pgEnum,
      integer,
      varchar,
      boolean,
      date,
      timestamp,
      text,
      real,
    } from 'drizzle-orm/pg-core';

    export const recordTypeEnum = pgEnum('record_type', [
      'period',
      'days_sum',
      'balance_reset',
    ]);

    export const employees = pgTable('employees', {
      id:        integer('id').primaryKey().generatedAlwaysAsIdentity(),
      fullName:  varchar('full_name', { length: 255 }).notNull(),
      hireDate:  date('hire_date', { mode: 'string' }).notNull(),
      isActive:  boolean('is_active').default(true).notNull(),
      isDeel:    boolean('is_deel').default(false).notNull(),
      email:     varchar('email', { length: 255 }),
      createdAt: timestamp('created_at', { withTimezone: true }).defaultNow().notNull(),
    });

    export const vacationRecords = pgTable('vacation_records', {
      id:         integer('id').primaryKey().generatedAlwaysAsIdentity(),
      employeeId: integer('employee_id').notNull().references(() => employees.id),
      recordType: recordTypeEnum('record_type').notNull(),
      startDate:  date('start_date', { mode: 'string' }),
      endDate:    date('end_date', { mode: 'string' }),
      daysCount:  real('days_count'),
      year:       integer('year'),
      note:       text('note'),
      createdAt:  timestamp('created_at', { withTimezone: true }).defaultNow().notNull(),
    });
    ```

    Critical notes:
    - All date-only columns (hireDate, startDate, endDate) use `date('col_name', { mode: 'string' })` — NOT timestamp. This returns 'YYYY-MM-DD' strings from queries, which vacationLogic.ts expects via parseISO().
    - employeeId FK uses manual references (no ON DELETE CASCADE) — deletion cascade is handled in the service layer to match Electron behavior.
    - recordTypeEnum column name must match the enum name: `recordTypeEnum('record_type')`.
